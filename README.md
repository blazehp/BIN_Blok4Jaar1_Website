## Blok 4 Jaar 1 Bio-Informatica Python Website

### Install `Required` Packages
```shell
pip install -r requirements.txt
```

## On First Launch
### Creating VENV
```bash
python -m venv .venv
```
### Activating VENV ( windows )
```bash
.\.venv\Scripts\activate
```
### Installing Packages
```bash
pip install -r requirements.txt
```

### Running app
```bash
python3 app.py
```
