The project

An end-to-end sequence analysis platform

This project investigates the microbial and fungal life found in hot compost. Sequences collected from the samples are submitted to the NCBI BLAST service, parsed, and persisted into a relational database.

The web platform makes that pipeline tangible: an admin dashboard manages the raw and filtered hits, the BLAST page presents the matches in a clean table, and the analysis view visualises the taxonomic spread of every organism we identify.

How it works

From sequence to species

  1. 01

    Input

    Raw nucleotide sequences are imported and stored, each tagged with a unique run identifier.

  2. 02

    BLAST

    Every sequence is queried against the NCBI nr database using blastx.

  3. 03

    Filter

    Hits are scored and filtered on e-value, identity and bit-score to keep only confident matches.

  4. 04

    Analyse

    Proteins and organisms are normalised into tables and visualised as a taxonomic sunburst.
